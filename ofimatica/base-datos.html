BIENVENIDO AL CURSO DE BASE DE DATOS

En este curso conocerás cómo se guardan los datos en una base de datos y aprenderás SQL, el lenguaje que se usa para crear tablas, consultar información y modificarla.

Lo que aprenderás

Al terminar el curso podrás:

  • Entender qué es una base de datos, una tabla, un registro y un campo.
  • Crear tablas con CREATE TABLE y elegir tipos de datos básicos.
  • Agregar, modificar y eliminar datos con INSERT, UPDATE y DELETE.
  • Consultar información con SELECT, WHERE y ORDER BY.
  • Relacionar tablas con claves primarias, claves foráneas y JOIN.
